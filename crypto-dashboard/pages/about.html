CryptoDash

A free, real-time cryptocurrency tracking dashboard built as a demonstration of live API integration, responsive design, and modern vanilla JavaScript.

→ Open Dashboard
What's Inside
📡
Live Market Data

Real-time crypto prices, market cap, 24h volume, and dominance stats fetched from the CoinGecko public API — no signup required.

📈
Interactive Charts

7-day, 30-day, and 90-day price history charts rendered with Chart.js. Hover tooltips, gradient fills, and color-coded trends (green/red).

🔍
Smart Search

Search any of 10,000+ cryptocurrencies with live autocomplete suggestions, ranking info, and instant detail loading.

⭐
Favorites (LocalStorage)

Star any coin to save it to your personal watchlist. Favorites persist across sessions using the browser's LocalStorage — no account needed.

💱
Currency Converter

Convert between USD and INR using a live exchange rate fetched from the CoinGecko simple price endpoint. Swap direction with one click.

🏆
Top Gainers & Losers

See which coins are pumping or dumping in the last 24 hours — ranked by percentage change from the top 20 coins by market cap.

🌙
Dark / Light Mode

Toggle between a dark finance aesthetic and a clean light theme. Your preference is saved to localStorage and persists across pages.

📱
Fully Responsive

Mobile-first layout with adaptive grids, collapsible navigation, and optimized typography for every screen size.
